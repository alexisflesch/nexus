# Watercolor assets

This directory contains the raster artwork used by `nexus-aquarelle.sty`:

- `bandeau-chap*.png`: chapter header washes;
- `pied-compose-chap*.png` and `pied-compose-sommaire.png`: full-width footer washes with the chapter tabs;
- `onglet-cible-chap*.png`: watercolor table-of-contents swatches;
- `bleu*.png`, `peche-fond.png` and `trait-crayon.png`: box backgrounds and margin strokes;
- `icone-*.png`: replacements for the illustrated course environment icons.

The painted elements are pre-rendered to keep XeLaTeX compilation practical. Keep all these files in the `aquarelle/` directory beside the package. Chapter colors and the live navigation text are still handled by TeX.
